FORGOT YOUR PASSWORD?

STAFF ACCOUNTS
Staff cannot recover a password themselves. Ask your Admin to set a new
password for you in Admin Settings. The Admin selects your account, types a
new password, and saves. Your other sessions are signed out automatically.

ADMIN ACCOUNT
The Admin recovers the account with a recovery code - a one-time code in the
form XXXX-XXXX-XXXX.

1. On the login page, select "Forgot password?".
2. Enter your username.
3. Enter one unused recovery code, plus your new password twice.
4. Sign in with your new password.

DETAILS
- Each recovery code works exactly once and is destroyed after use.
- Codes do not expire, but generating a new set immediately kills the old one.
- The Admin can generate a new set in Admin Settings > My Recovery Codes.
- Recovery codes are shown once. Only hashes are stored, so nobody can read
  them back later.
- Anyone holding a recovery code can reset the Admin password. Treat the codes
  like a password: printed and stored offline, never in chat or screenshots.

ADMIN LOCKOUT (lost password AND lost codes)
Your system operator can recover the Admin account from the Backend folder:

    npm run reset:admin

This sets a new Admin password and issues a fresh set of recovery codes.

Never share your password or a recovery code with anyone.
